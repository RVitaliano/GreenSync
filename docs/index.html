Visão Geral (Estado Atual)

O GreenSync é um projeto de vaso inteligente projetado para monitorar dados vitais da planta e automatizar a irrigação. Na etapa atual de desenvolvimento (N1), o protótipo utiliza um ESP32-WROOM para ler sensores de temperatura/umidade do ar (DHT22) e umidade do solo (YL-69), simulando a irrigação e publicando os dados na nuvem via MQTT.

Para as próximas fases, o projeto integrará um segundo microcontrolador (ESP32-S3) com display OLED e microfone. Isso habilitará um assistente de voz com personalidade própria (via Google Gemini) capaz de interagir com o usuário e agendar regas, além de um portal Wi-Fi para configuração dinâmica de rede.

Fases do Projeto

  • Fase Atual (N1): Leitura base de sensores (DHT22 e YL-69), acionamento de hardware (simulado via servomotor/relé), comunicação MQTT com broker EMQX e persistência básica.
  • Próximos Passos (Integração IA): Implementação do ESP32-S3 para áudio, integração com sensor de pH e bomba d'água real, hospedagem do backend em servidor dedicado (Render), display OLED interativo e portal de configuração Wi-Fi.
  • V2 (Expansão): Conectividade celular via módulo GPRS no ESP32-WROOM, tornando o vaso totalmente independente de redes locais.
