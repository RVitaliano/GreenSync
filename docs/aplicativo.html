Aplicativo Mobile (Flutter)

O aplicativo sincroniza os dados do vaso inteligente em tempo real através do Firebase (Firestore), permitindo o monitoramento do pH, umidade, temperatura e controle da irrigação.

Estrutura de Dados (Firestore)

A comunicação Backend ↔ App ocorre através da seguinte estrutura:


devices/{deviceId}
  ├── status, last_seen
  ├── leitura_atual: { ph, umidade_solo, temperatura_ar, umidade_ar, bomba_ligada, updated_at }
  ├── historico/{autoId}: ph, umidade_solo, temperatura_ar, umidade_ar, bomba_ligada, timestamp
  └── agendamentos/{id}: executar_em, duracao_s, status, origem, criado_em (planejado)
