Aplicativo Mobile (Flutter)

Desenvolvido em Flutter / Dart, o aplicativo é a interface de acompanhamento e controle do ecossistema GreenSync. Ele sincroniza os dados diretamente do Firebase Firestore em tempo real, envia pedidos de rega ao backend e configura a rede Wi-Fi do vaso via Bluetooth Low Energy (BLE).

  • Dashboard em tempo real: Exibe temperatura do ar, umidade do ar, umidade do solo, pH e estado da bomba sem precisar recarregar a tela.
  • Status de conexão: Indica se o vaso está online ou offline (via Last Will MQTT).
  • Seleção dinâmica: Suporte para acompanhar múltiplos vasos.
  • Histórico em gráficos: Visualização da evolução das leituras ao longo do tempo com fl_chart.
  • Provisionamento Wi-Fi por BLE: Envio das credenciais de rede (2,4 GHz) ao dispositivo GreenSync_BLE via flutter_blue_plus com retorno em tempo real (conectando, ok, erro:senha, erro:rede ou erro:timeout).

Estrutura de Dados (Firestore)

Coleções consumidas pelo aplicativo e gerenciadas pelo backend:

devices/{deviceId}
  ├── status, last_seen, fw, ota
  ├── leitura_atual: { ph, umidade_solo, temperatura_ar, umidade_ar, bomba_ligada, updated_at }
  ├── historico/{autoId}: ph, umidade_solo, temperatura_ar, umidade_ar, bomba_ligada, timestamp
  └── agendamentos/{id}: quando, duracao_s, status, origem, motivo, criado_em, atualizado_em

firmware/{alvo}
  └── versao, url, sha256, notas, anterior, bloqueadas

Como Executar Localmente

Requer Flutter SDK compatível com Android SDK 37+ e um aparelho físico Android para testar o Bluetooth (BLE):

cd app
flutter pub get
dart pub global run flutterfire_cli:flutterfire configure
flutter run
