Hardware Utilizado

  • ESP32-WROOM: Responsável pela leitura dos sensores (DHT22, YL-69, pH), controle da bomba de água e comunicação via MQTT.
  • ESP32-S3: Responsável pela interface de voz (microfone e alto-falante), comunicando-se via HTTP.

Contratos MQTT (QoS 1)

Tópico de Leituras: greensync/{deviceId}/sensores


{
  "ph": 6.4,
  "umidade_solo": 42,
  "temperatura_ar": 24.1,
  "umidade_ar": 58,
  "bomba_ligada": false,
  "timestamp": 1735000000
}

Nota: umidade_ar e timestamp são opcionais. umidade_solo já vem em % (calibrado). Se o DHT22 falhar, o firmware não publica.

Tópico de Status: greensync/{deviceId}/status

{"status": "online"} // ou offline via Last Will
